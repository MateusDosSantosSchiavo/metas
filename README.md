# Meta da Factor 2019

Página interativa para acompanhar o progresso da meta de comprar uma Yamaha Factor 2019 (R$ 12.000) e separar 3 meses de aluguel (R$ 800 por mês).

Você informa quanto já guardou, quanto guarda por mês e o rendimento ao mês, e as barras de progresso mostram o que já foi separado, o que falta e a previsão de quando cada meta chega.

## Como usar

Abra o `index.html` no navegador, ou acesse a versão publicada no GitHub Pages.

## Observações

- Os valores ficam salvos apenas no navegador de quem usa a página.
- O rendimento é uma simulação, o saldo real pode variar.
- A meta não inclui CNH nem equipamentos de segurança.
